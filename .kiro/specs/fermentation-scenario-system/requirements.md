# 발효 시나리오 시스템 요구사항

## 소개

현재 발효 시스템은 사용자가 매번 복잡한 계산을 해야 하는 문제가 있습니다. 새로운 시나리오 기반 시스템은 AI가 모든 계산을 담당하고, 사용자는 완성된 시나리오를 선택하여 단순히 따라하기만 하면 되는 혁신적인 접근법을 제공합니다.

## 요구사항

### 요구사항 1: 실온 발효 시나리오 시스템

**사용자 스토리:** 베이킹을 하는 사용자로서, 실온 발효 시 복잡한 계산 없이 완성된 시나리오를 받아 단순히 따라하고 싶습니다.

#### 승인 기준

1. WHEN 사용자가 실온 발효를 선택하면 THEN 시스템은 현재 환경(온도, 습도)과 레시피를 분석하여 최적의 발효 시나리오를 자동 생성해야 합니다
2. WHEN 일반 실온 발효가 선택되면 THEN 시스템은 1차 발효, 분할/성형 휴지, 최종 발효의 정확한 시간과 조건을 제공해야 합니다
3. WHEN 냉장 저온 발효가 선택되면 THEN 시스템은 냉장고 설정 온도, 저온 발효 시간, 해동 시작 시간, 최종 발효 조건을 자동 계산해야 합니다
4. WHEN 냉동 오버나이트가 선택되면 THEN 시스템은 냉동 보관 조건, 해동 스케줄, 사용 가능 시간을 자동 제공해야 합니다
5. WHEN 환경 조건이 변경되면 THEN 시스템은 실시간으로 시나리오를 재계산하고 업데이트해야 합니다

### 요구사항 2: 발효기 발효 가이드 시스템

**사용자 스토리:** 발효기를 사용하는 사용자로서, 각 단계별 최적 온도/습도/시간 설정값을 받아 내 발효기를 직접 설정하고 싶습니다.

#### 승인 기준

1. WHEN 사용자가 발효기 모드를 선택하면 THEN 시스템은 레시피 분석을 통해 각 발효 단계별 최적 온도, 습도, 시간을 자동 계산해야 합니다
2. WHEN 발효기 설정이 필요하면 THEN 시스템은 명확한 설정값과 설정 방법을 단계별로 안내해야 합니다
3. WHEN 오버나이트 발효나 냉동 보관이 필요하면 THEN 시스템은 안전한 온도 설정과 시간을 계산하여 사용자에게 제공해야 합니다
4. WHEN 발효 단계가 완료되면 THEN 시스템은 다음 단계의 설정값과 변경 방법을 안내해야 합니다
5. WHEN 사용자가 설정을 완료하면 THEN 시스템은 해당 단계의 타이머를 시작하고 완료 알림을 제공해야 합니다

### 요구사항 3: AI 시나리오 엔진

**사용자 스토리:** 사용자로서, 복잡한 발효 과학을 이해하지 못해도 AI가 모든 것을 계산해서 완벽한 결과를 얻고 싶습니다.

#### 승인 기준

1. WHEN 레시피가 입력되면 THEN AI는 재료 특성(강력분, 설탕, 이스트 등)을 분석하여 발효 특성을 파악해야 합니다
2. WHEN 환경 조건이 감지되면 THEN AI는 현재 온도, 습도를 반영하여 발효 시간을 자동 조정해야 합니다
3. WHEN 장비 정보가 제공되면 THEN AI는 발효기 종류, 냉장고 성능 등을 고려하여 최적 시나리오를 생성해야 합니다
4. WHEN 시나리오가 생성되면 THEN AI는 각 단계별 구체적인 행동 지침과 타이밍을 제공해야 합니다
5. WHEN 예상치 못한 상황이 발생하면 THEN AI는 실시간으로 시나리오를 재계산하고 대안을 제시해야 합니다

### 요구사항 4: 통합 타이머 및 알림 시스템

**사용자 스토리:** 사용자로서, 발효 과정 중 시간을 체크하거나 다음 단계를 기억할 필요 없이 자동 알림을 받고 싶습니다.

#### 승인 기준

1. WHEN 시나리오가 시작되면 THEN 시스템은 모든 단계의 타이머를 자동으로 설정하고 관리해야 합니다
2. WHEN 각 단계가 완료되면 THEN 시스템은 명확한 알림과 함께 다음 행동을 안내해야 합니다
3. WHEN 냉장/냉동 단계에서 THEN 시스템은 해동 시작 시간, 사용 가능 시간을 사전에 알려주어야 합니다
4. WHEN 오븐 예열이 필요하면 THEN 시스템은 최적 타이밍에 예열 알림을 보내야 합니다
5. WHEN 사용자가 부재중이면 THEN 시스템은 다양한 알림 방식(푸시, 소리, 진동)으로 중요한 단계를 놓치지 않게 해야 합니다

### 요구사항 5: 시나리오 선택 및 관리 인터페이스

**사용자 스토리:** 사용자로서, 복잡한 설정 없이 직관적인 인터페이스로 원하는 발효 방식을 선택하고 싶습니다.

#### 승인 기준

1. WHEN 사용자가 발효 화면에 진입하면 THEN 시스템은 실온 발효와 발효기 발효 중 선택할 수 있는 명확한 옵션을 제공해야 합니다
2. WHEN 실온 발효가 선택되면 THEN 시스템은 일반/냉장 저온/냉동 오버나이트 옵션을 제공해야 합니다
3. WHEN 발효기 발효가 선택되면 THEN 시스템은 스마트 발효기/일반 발효기 옵션을 제공해야 합니다
4. WHEN 시나리오가 생성되면 THEN 시스템은 전체 과정을 한눈에 볼 수 있는 타임라인을 제공해야 합니다
5. WHEN 시나리오가 진행 중이면 THEN 사용자는 현재 단계, 남은 시간, 다음 행동을 명확히 확인할 수 있어야 합니다

### 요구사항 6: 실시간 모니터링 및 적응 시스템

**사용자 스토리:** 사용자로서, 환경이 변하거나 예상과 다른 상황이 발생해도 시스템이 자동으로 대응해주기를 원합니다.

#### 승인 기준

1. WHEN 실온이 예상보다 높거나 낮으면 THEN 시스템은 발효 시간을 자동 조정하고 사용자에게 알려야 합니다
2. WHEN 습도가 크게 변하면 THEN 시스템은 반죽 상태 변화를 예측하고 대응 방안을 제시해야 합니다
3. WHEN 발효가 예상보다 빠르거나 느리면 THEN 시스템은 실시간으로 남은 시간을 재계산해야 합니다
4. WHEN 냉장고나 발효기 온도가 설정값과 다르면 THEN 시스템은 조정 방법과 영향을 설명해야 합니다
5. WHEN 긴급 상황(정전, 장비 고장 등)이 발생하면 THEN 시스템은 대체 방안을 즉시 제시해야 합니다
