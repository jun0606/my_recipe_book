# 발효 시나리오 시스템 구현 계획

## 구현 개요

이 구현 계획은 기존의 복잡한 발효 계산 시스템을 완전 시나리오 기반 시스템으로 전환하는 작업을 단계별로 정의합니다. AI가 모든 계산을 담당하고 사용자는 단순히 시나리오를 선택하여 실행하는 혁신적인 접근법을 구현합니다.

## 구현 작업

- [ ] 1. 핵심 데이터 모델 및 인터페이스 구축
  - 발효 시나리오의 기본 데이터 구조 정의
  - 시나리오 단계, 사용자 지침, 자동화 액션 모델 구현
  - 환경 조건, 장비 프로파일, 레시피 분석 모델 생성
  - _요구사항: 1.1, 2.1, 3.1_

- [x] 2. AI 시나리오 엔진 핵심 로직 구현

  - 환경 조건 평가 로직 구현 (온도, 습도 반영)

  - 냉동 오버나이트 시나리오 생성 로직 구현

  - 오버나이트/냉동 보관 안전 설정 계산 로직 구현
