# AI 협업 및 프로젝트 관리 가이드

## 1. 개요

이 문서는 AI와 효과적으로 협업하여 프로젝트를 관리하고 개발하는 방법을 설명합니다. 초보 개발자도 쉽게 따라할 수 있는 단계별 가이드를 제공합니다.

## 2. 핵심 문서 관리 전략

### 2.1 관리할 문서 목록

프로젝트의 완전성과 품질을 위해 다음 문서들을 모두 관리하세요:

1. **feature_catalog.md** (루트 디렉토리): 모든 기능 목록과 상태
2. **app_structure.md** (루트 디렉토리): 앱 구조와 파일 위치
3. **known_issues.md** (루트 디렉토리): 현재 문제점과 해결 방법
4. **development_guidelines.md** (루트 디렉토리): 코드 작성 규칙과 개발 표준
5. **api_documentation.md** (루트 디렉토리): 내부 API 및 외부 서비스 연동 정보
6. **version_history.md** (루트 디렉토리): 앱 버전별 변경 사항 기록
7. **testing_documentation.md** (루트 디렉토리): 테스트 전략 및 결과
8. **user_feedback.md** (루트 디렉토리): 사용자 피드백 및 개선 계획
9. **environment_setup.md** (루트 디렉토리): 개발 환경 설정 방법
10. **data_models.md** (루트 디렉토리): 데이터 구조 및 관계 설명
11. **document_update_guide.md** (루트 디렉토리): 문서 업데이트 지침
12. **code_quality_guidelines.md** (루트 디렉토리): 코드 품질 관리 및 중복 코드 방지 지침
13. **ai_code_modification_guidelines.md** (루트 디렉토리): AI가 코드 수정 시 따라야 할 안전한 리팩토링 지침
14. **project_documentation_guidelines.md** (루트 디렉토리): 프로젝트 문서화 가이드라인
15. **ai_hallucination_prevention_guide.md** (루트 디렉토리): AI 할루시네이션 감지 및 방지 방법

**참고**: AI는 이러한 문서들을 자동으로 참조하고 업데이트할 것입니다. 사용자가 매번 이 문서들을 제공하거나 업데이트를 지시할 필요가 없습니다.

### 2.2 문서 참조 가이드

각 상황에 맞는 문서를 참조하여 일관된 개발과 문서화를 유지하세요:

1. **코드 작성 시**:
   - **development_guidelines.md**: 코드 스타일과 패턴 확인
   - **code_quality_guidelines.md**: 중복 코드 방지 및 품질 관리 지침 참조
   - **data_models.md**: 데이터 구조 이해 및 일관성 유지

2. **코드 수정/리팩토링 시**:
   - **ai_code_modification_guidelines.md**: 안전한 코드 수정 방법 참조
   - **feature_catalog.md**: 기존 기능 동작 이해
   - **known_issues.md**: 관련 이슈 확인

3. **오류 해결 시**:
   - **known_issues.md**: 유사한 오류 해결 방법 확인
   - **testing_documentation.md**: 테스트 방법 참조

4. **문서화 작업 시**:
   - **project_documentation_guidelines.md**: 문서화 표준 및 템플릿 참조
   - **document_update_guide.md**: 문서 업데이트 프로세스 확인

5. **API 개발/통합 시**:
   - **api_documentation.md**: API 스펙 및 사용법 참조

6. **프로젝트 구조 변경 시**:
   - **app_structure.md**: 현재 구조 이해 및 일관성 유지
   
7. **AI 할루시네이션 방지 시**:
   - **ai_hallucination_prevention_guide.md**: 할루시네이션 감지 및 방지 방법 참조

### 2.3 문서 업데이트 방법

1. AI에게 변경 사항을 알려주세요
2. AI가 문서 업데이트를 도와드립니다
3. 업데이트된 문서를 저장하세요

## 3. AI 협업 워크플로우

### 3.1 기능 추가/수정 전 (계획 단계)

```
# AI와 회의 시작하기

안녕하세요, 다음 기능을 추가/수정하려고 합니다: [기능 설명]

다음 파일을 참조해주세요:
1. feature_catalog.md
2. app_structure.md
3. known_issues.md (관련 이슈가 있는 경우)

이 기능 구현에 대한 조언과 접근 방법을 알려주세요.
```

### 3.2 코드 작성 단계

```
# AI에게 코드 요청하기

[기능 이름]을 구현하기 위한 코드를 작성해주세요.

구현 요구사항:
1. [요구사항 1]
2. [요구사항 2]
3. [요구사항 3]

관련 파일: [파일 경로]
```

### 3.3 코드 수정 전 (롤백 계획)

```
# 롤백 계획 요청하기

다음 코드를 수정하려고 합니다:
[코드 또는 파일 경로]

문제가 발생할 경우를 대비한 롤백 계획을 알려주세요.
```

### 3.4 테스트 및 오류 해결

```
# 오류 해결 요청하기

다음 코드를 실행했을 때 오류가 발생했습니다:
[오류 메시지]

코드:
[문제가 있는 코드]

이 오류를 해결하는 방법을 알려주세요.
```

### 3.5 문서 업데이트

```
# 문서 업데이트 요청하기

방금 다음 기능을 추가/수정했습니다: [기능 설명]

변경된 파일:
- [파일 경로 1]
- [파일 경로 2]

변경 내용 요약:
1. [주요 변경 사항 1]
2. [주요 변경 사항 2]

다음 문서들을 업데이트해주세요:
1. feature_catalog.md - 기능 목록 및 상태 업데이트
2. app_structure.md - 새 파일 추가 (필요한 경우)
3. known_issues.md - 해결된 이슈 업데이트

또한 모든 업데이트된 문서에 메타데이터(최종 업데이트 날짜, 관련 문서 등)를 추가해주세요.

## 5. 파일 관리 전략

### 5.1 중요 파일 백업

1. Git을 사용하여 변경 사항 커밋
2. 주요 변경 전 전체 프로젝트 폴더 복사
3. 중요 마일스톤에서 zip 백업 생성

### 5.2 파일 구조 유지

새 파일을 추가할 때는 app_structure.md에 정의된 구조를 따르세요:

- `lib/models/`: 데이터 모델 클래스
- `lib/providers/`: 상태 관리 Provider
- `lib/screens/`: 화면 UI
- `lib/services/`: 비즈니스 로직 서비스
- `lib/utils/`: 유틸리티 클래스
- `lib/widgets/`: 재사용 가능한 위젯

## 7. 문제 해결 가이드

### 7.1 일반적인 오류 해결 방법

1. 오류 메시지를 정확히 복사
2. 오류가 발생한 파일과 라인 번호 확인
3. AI에게 전체 맥락과 함께 오류 제공
4. AI의 제안을 단계별로 적용

### 7.2 변경 사항 추적

간단한 변경 로그를 유지하세요:

```
# 변경 로그

날짜: YYYY-MM-DD
변경 내용: [간단한 설명]
변경된 파일: [파일 목록]
```

### 7.3 기능 유실 방지 및 복구

기능 유실이 발생했을 때 다음 단계를 따르세요:

1. **기능 유실 확인**
   - 어떤 기능이 작동하지 않는지 정확히 파악
   - feature_catalog.md에서 해당 기능의 원래 동작 확인

2. **AI에게 기능 복구 요청**
```
# 기능 유실 복구 요청

다음 기능이 작동하지 않습니다: [기능 설명]

원래 동작: [원래 어떻게 작동했는지 설명]
현재 동작: [현재 어떻게 작동하는지 또는 작동하지 않는지 설명]

관련 파일: [파일 경로]

이 기능을 복구하는 방법을 알려주세요.
```

3. **백업에서 복원**
   - 기능이 작동했던 마지막 백업 확인
   - 필요한 코드만 선택적으로 복원

### 7.4 잘못된 코드 수정

AI가 잘못 추가한 코드를 처리하는 방법:

1. **문제 코드 식별**
   - 문제가 되는 코드 부분 식별
   - 어떤 문제를 일으키는지 확인 (오류 메시지, 비정상 동작 등)

2. **AI에게 코드 수정 요청**
```
# 잘못된 코드 수정 요청

다음 코드에 문제가 있습니다:
```dart
// 문제가 있는 코드
```

문제 설명: [코드가 어떤 문제를 일으키는지 설명]

이 코드를 올바르게 수정해주세요.
```

3. **코드 비교 및 검증**
   - 수정된 코드와 원래 코드 비교
   - 수정된 코드가 원래 기능을 유지하는지 확인
   - 테스트 후 적용

### 7.5 반복되는 오류 해결

같은 오류가 반복해서 발생할 때:

1. **패턴 파악**
   - 오류가 발생하는 특정 상황이나 조건 파악
   - 공통적인 원인 식별

2. **근본 원인 해결 요청**
```
# 반복 오류 해결 요청

다음 오류가 반복해서 발생합니다:
[오류 메시지]

발생 패턴: [오류가 발생하는 상황 설명]
시도한 해결책: [이미 시도한 해결책 설명]

이 문제의 근본 원인과 영구적인 해결책을 알려주세요.
```

3. **예방 전략 수립**
   - 유사한 오류를 방지하기 위한 코딩 패턴 적용
   - 자동화된 테스트 추가 고려

## 8. 프로젝트 성장 관리

### 8.1 단계적 접근법

2. 작은 단위로 개발 및 테스트

3. 정기적으로 기술 부채 해결 시간 할당

## 9. AI 협업 팁

### 9.1 효과적인 프롬프트 작성법

- 구체적인 질문하기
- 원하는 결과물 명확히 설명하기
- 관련 코드 제공하기
- 이전 시도와 결과 공유하기

### 9.2 AI 한계 이해하기

- AI는 실시간 데이터에 접근할 수 없음
- 프로젝트의 모든 파일을 동시에 볼 수 없음
- 실행 환경을 직접 테스트할 수 없음
- 때로는 여러 번 시도가 필요할 수 있음

### 9.3 코드 변경 검증 전략

AI가 제안한 코드 변경을 적용하기 전에:

1. **변경 사항 이해하기**
   - 각 변경 사항이 무엇을 해결하는지 이해
   - 변경 사항이 다른 기능에 미치는 영향 고려

2. **점진적 적용**
   - 모든 변경을 한 번에 적용하지 않고 작은 단위로 나누어 적용
   - 각 변경 후 테스트 수행

3. **변경 전후 비교**
   - 변경 전 코드와 변경 후 코드를 비교
   - 의도하지 않은 변경이 없는지 확인

4. **테스트 케이스 작성**
```
# 테스트 케이스 요청

다음 코드에 대한 테스트 케이스를 작성해주세요:
```dart
// 테스트할 코드
```

이 코드가 올바르게 작동하는지 확인하는 방법을 알려주세요.
```

### 11.4 잘못된 코드 수정 예시

```
AI가 추가한 다음 코드에 문제가 있습니다:

```dart
void calculateIngredients() {
  for (var ingredient in ingredients) {
    // 이 부분에서 오류 발생
    final amount = double.parse(ingredient.amount);
    final multiplier = getMultiplier();
    ingredient.calculatedAmount = amount * multiplier;
  }
}
```

문제 설명: 
1. ingredient.amount가 이미 double 타입인데 double.parse를 사용하고 있음
2. ingredient 객체에 calculatedAmount 속성이 없음

이 코드를 올바르게 수정해주세요.
```
