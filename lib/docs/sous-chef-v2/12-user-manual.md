## 🥖 빵 모듈 사용법

### 1. 빵 레시피 분석

#### 기본 분석 절차
```dart
1. 빵 모듈 선택
2. 레시피 입력 또는 선택
   - 재료 및 양
   - 공정 단계
   - 장비 설정
3. 분석 시작 버튼 탭
4. 결과 확인
   - 종합 점수 (0-100점)
   - 개선 제안
   - 상세 분석
```

#### 분석 결과 해석
```dart
// 점수 등급 기준
- 90-100점: 탁월함 (Excellent)
- 80-89점: 좋음 (Good)
- 70-79점: 보통 (Fair)
- 60-69점: 개선 필요 (Needs Improvement)
- 0-59점: 큰 개선 필요 (Major Improvement Needed)
```
