## 📋 추가된 기능

### 1. 2차 발효 단계 추가 ✅
**새로운 발효 단계**:
```dart
enum FermentationStage {
  bulk,           // 1차 발효 (Bulk Fermentation)
  secondary,      // 2차 발효 (Secondary Fermentation) ← 새로 추가
  divided,        // 분할 후 휴지 (Post-Division Rest)
  shaped,         // 성형 후 발효 (Post-Shaping Rest)
  finalProof,     // 최종 발효 (Final Proof)
  overnight,      // 오버나이트 발효 (Overnight Fermentation)
  coldRetard,     // 냉장 숙성 (Cold Retardation)
}
```

### 2. 2차 발효 특성 정의 ✅
**기본 설정**:
- **시간**: 90분 (1시간 30분)
- **온도**: 25°C (1차보다 약간 낮음)
- **습도**: 75%

**특징**:
- 1차 발효보다 온화한 조건에서 진행
- 글루텐 구조 안정화 및 풍미 발달
- 반죽의 탄력과 질감 개선

### 3. 프리셋 시나리오 업데이트 ✅
**업데이트된 프리셋**:

- 🚀 **빠른 식빵**: 1차발효 → 최종발효 (변경 없음)
- 📋 **표준 식빵**: 1차 → **2차** → 분할 → 성형 → 최종 (2차 발효 추가)
- 🌙 **오버나이트**: 1차 → **2차** → 오버나이트 → 최종 (2차 발효 추가)
- 🍞 **사워도우**: 1차 → **2차** → 냉장숙성 → 최종 (2차 발효 추가)

### 4. 맞춤형 조언 시스템 확장 ✅
**2차 발효 전용 조언**:
```
🔄 2차 발효 (1시간 30분): 글루텐 구조 안정화
   • 1차 발효보다 온화한 조건에서 진행
   • 반죽의 탄력과 풍미가 더욱 발달
```

### 5. 시나리오 분석 고도화 ✅
**새로운 시나리오 타입**:
- **완전한 표준 식빵 공정**: 1차 + 2차 + 분할 + 성형 + 최종 (5단계)
- **표준 식빵 공정**: 1차 + 분할 + 성형 + 최종 (4단계, 기존)

## 🎨 실제 베이킹 공정 반영

### 전통적인 식빵 제조 공정
```
1️⃣ 1차 발효 (2시간)
   ↓
2️⃣ 2차 발효 (1시간 30분) ← 새로 추가
   ↓
3️⃣ 분할 후 휴지 (20분)
   ↓
4️⃣ 성형 후 발효 (15분)
   ↓
5️⃣ 최종 발효 (1시간)
   ↓
🔥 굽기
```

### 2차 발효의 역할
- **글루텐 네트워크 강화**: 1차 발효에서 형성된 글루텐 구조를 더욱 안정화
- **풍미 발달**: 이스트와 박테리아의 추가적인 발효 작용으로 깊은 맛 형성
- **질감 개선**: 반죽의 탄력성과 부드러움 향상
- **가스 보유력 증가**: 최종 제품의 부피와 질감 개선

```

   • 표면이 매끄러워지면 완료

   • 높은 습도(80%) 유지 필수
   • 과발효 시 오븐 스프링 감소

🌡️ 실내온도 적정: 모든 단계에서 안정적인 발효 진행
💡 전체 공정이 길어지므로 시간 계획을 잘 세우세요
```
