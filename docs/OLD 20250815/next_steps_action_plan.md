### 성능 모니터링:
```sql
-- 성능 데이터 확인
SELECT * FROM mcp_performance_monitor ORDER BY timestamp DESC LIMIT 10;

-- 서버 상태 확인
SELECT * FROM mcp_server_health WHERE is_active = 1;
```

### 최적화 규칙 확인:
```sql
-- 활성 최적화 규칙
SELECT * FROM mcp_optimization_rules WHERE is_active = 1;

-- 워크플로우 패턴
SELECT * FROM mcp_workflow_patterns ORDER BY workflow_name, step_order;
```

### Task Master AI 활용:
```powershell
# 프로젝트 초기화
mcp_task_master_ai_initialize_project -projectRoot "C:\path\to\project"

# 작업 생성
mcp_task_master_ai_add_task -projectRoot "C:\path\to\project" -prompt "새로운 기능 구현"
```
