# 🚀 Phase2 베이킹 계산기 기능 설명

## 📋 **사용자 질문 답변**

### ❓ **4. 빨간 카드 "bakingService가 등록되지 않았습니다" 오류**

#### 🔍 **문제 원인**
- **ServiceLocator 미초기화**: `main.dart`에서 `ServiceLocator.instance.initOnce()`가 호출되지 않았음
- **BakingService 미등록**: 의존성 주입 시스템에서 BakingService가 등록되지 않아 발생한 오류

#### 🔧 **해결 방법**
```dart
// main.dart에 추가
import 'di/service_locator.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // ServiceLocator 초기화 (BakingService 등록)
  ServiceLocator.instance.initOnce();
  
  // ... 나머지 코드
}
```

#### ✅ **해결 결과**
- BakingService가 정상적으로 등록됨
- 베이킹 계산기에서 더 이상 오류 발생하지 않음
- 모든 계산 모드가 정상 작동

### ❓ **5. 초록색 카드 "Phase2: 고급 계산 모드 및 커스터마이징 지원" 설명**

#### 🎯 **Phase2란?**
**Phase2**는 베이킹 계산기의 **2세대 업그레이드 버전**으로, 기존 Phase1의 기본 기능을 대폭 확장한 고급 베이킹 계산 시스템입니다.

#### 🚀 **Phase2의 주요 기능들**

##### 1. **7가지 고급 계산 모드**
```
✅ 배율 조정 (Scale Adjustment)
✅ 분할 계산 - 개수 기준 (Split by Count)  
✅ 분할 계산 - 무게 기준 (Split by Weight)
✅ 배율 + 분할 조합 (Scale and Split)
✅ 동적 비교 (Dynamic Comparison) - 🆕 Phase2 신규
✅ 최적 분할 (Optimal Split) - 🆕 Phase2 신규
✅ 커스텀 계산 (Custom Calculation) - 🆕 Phase2 신규
```

##### 2. **실시간 계산 시스템**
- **300ms 디바운싱**: 입력 중 불필요한 계산 방지
- **즉시 반영**: 값 변경 시 실시간으로 결과 업데이트
- **성능 최적화**: 대량 재료 처리 시에도 부드러운 동작

##### 3. **색상 코딩 시스템**
- **증가량**: 초록색으로 표시 (▲ +15.2%)
- **감소량**: 빨간색으로 표시 (▼ -23.1%)
- **변화 없음**: 회색으로 표시 (-)
- **직관적 인식**: 한눈에 변화량 파악 가능

##### 4. **커스터마이징 기능**
- **모드 순서 변경**: 자주 사용하는 모드를 위로 이동
- **즐겨찾기**: 자주 사용하는 모드에 ⭐ 표시
- **모드 숨기기**: 사용하지 않는 모드 숨김 처리
- **개인화**: 사용자별 맞춤 설정 저장

##### 5. **고급 분할 전략**
- **동적 비교**: 여러 분할 옵션을 비교하여 최적 선택 제안
- **최적 분할**: 재료 낭비를 최소화하는 분할 계산
- **효율성 분석**: 각 옵션의 효율성 점수 표시
- **남은 재료 최소화**: 가장 적은 재료가 남는 옵션 추천

##### 6. **반올림 설정**
- **0-3자리 정밀도**: 소수점 자릿수 선택 가능
- **스마트 반올림**: 재료 특성에 맞는 반올림 적용
- **일관성 유지**: 모든 계산에서 동일한 반올림 규칙 적용

##### 7. **요리 모드 통합**
- **재료 하이라이트**: 요리 단계에 맞는 재료 강조 표시
- **단계별 안내**: 현재 필요한 재료량 실시간 표시
- **스크롤 연동**: 자동으로 해당 재료로 스크롤 이동

#### 🆚 **Phase1 vs Phase2 비교**

| 기능 | Phase1 | Phase2 |
|------|--------|--------|
| **계산 모드** | 3개 기본 모드 | 7개 고급 모드 |
| **실시간 계산** | 수동 계산 | 300ms 디바운싱 |
| **색상 코딩** | 없음 | 직관적 색상 시스템 |
| **커스터마이징** | 고정 UI | 완전 커스터마이징 |
| **고급 전략** | 없음 | 동적 비교, 최적 분할 |
| **반올림 설정** | 고정 | 0-3자리 선택 가능 |
| **요리 모드** | 기본 연동 | 완전 통합 |
| **성능** | 기본 | 대폭 최적화 |

#### 🎨 **초록색 카드의 의미**
초록색 카드는 **"새로운 기능 안내"** 역할을 합니다:
- **색상**: 초록색 = 새로운 기능, 업그레이드
- **위치**: 계산기 하단에 표시
- **목적**: 사용자에게 Phase2의 고급 기능들을 알림
- **디자인**: 작고 깔끔하게 표시하여 방해하지 않음

#### 💡 **Phase2 사용 팁**

##### 🔧 **고급 설정 활용**
1. **고급 설정 버튼** (⚙️) 클릭
2. **동적 비교**, **최적 분할** 등 고급 기능 설명 확인
3. **모드 커스터마이징** 다이얼로그에서 순서 변경

##### 🎯 **최적 분할 활용**
1. **최적 분할 모드** 선택
2. **목표 무게** 또는 **목표 개수** 입력
3. **여러 옵션 비교** 결과 확인
4. **가장 효율적인 옵션** 선택

##### 🎨 **색상 코딩 읽기**
- **초록색 ▲**: 원본보다 증가 (더 많이 필요)
- **빨간색 ▼**: 원본보다 감소 (더 적게 필요)
- **회색 -**: 변화 없음

#### 🚀 **Phase2의 장점**

##### ⚡ **효율성**
- **20배 빠른 계산**: 수동 계산 대비 대폭 향상
- **실시간 반응**: 입력과 동시에 결과 확인
- **메모리 최적화**: 대량 재료 처리 시에도 부드러운 동작

##### 🎯 **정확성**
- **정밀한 계산**: 소수점 이하 정확한 계산
- **오차 최소화**: 반올림 오차 최소화 알고리즘
- **일관성 보장**: 모든 모드에서 동일한 계산 기준

##### 🎨 **사용성**
- **직관적 UI**: 색상과 아이콘으로 쉬운 이해
- **개인화**: 사용자별 맞춤 설정
- **접근성**: 모든 사용자가 쉽게 사용 가능
