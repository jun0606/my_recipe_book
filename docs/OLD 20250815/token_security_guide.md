# 토큰 보안 가이드

## 개요

이 문서는 프로젝트에서 API 키, 액세스 토큰 및 기타 민감한 자격 증명을 안전하게 관리하는 방법에 대한 가이드입니다.

## 토큰 관리 원칙

1. **절대 토큰을 Git에 커밋하지 마세요**
   - 모든 토큰과 API 키는 `.gitignore`에 포함된 파일에만 저장해야 합니다.
   - 실수로 토큰이 커밋된 경우 즉시 해당 토큰을 무효화하고 새 토큰을 발급받으세요.

2. **템플릿 파일 사용**
   - 토큰이 필요한 설정 파일은 `.template` 확장자를 가진 템플릿 파일을 제공합니다.
   - 개발자는 이 템플릿을 복사하여 자신의 토큰으로 대체해야 합니다.

3. **환경 변수 활용**
   - 가능하면 토큰을 환경 변수로 관리하세요.
   - 로컬 개발 환경에서는 `.env` 파일을 사용하고, 이 파일도 `.gitignore`에 포함시키세요.

## MCP 설정 파일 설정 방법

1. `.kiro/settings/mcp.json.template` 파일을 `.kiro/settings/mcp.json`으로 복사합니다:
   ```
   copy .kiro\settings\mcp.json.template .kiro\settings\mcp.json
   ```

2. 복사한 파일에서 플레이스홀더를 실제 토큰 값으로 대체합니다:
   - `YOUR_GITHUB_TOKEN_HERE`를 실제 GitHub 토큰으로 대체
   - `YOUR_PROJECT_PATH_HERE`를 실제 프로젝트 경로로 대체 (예: `C:/Users/username/my_recipe_book`)

3. 이 파일은 `.gitignore`에 포함되어 있으므로 Git에 커밋되지 않습니다.

## 토큰 유출 시 대응 방법

1. **즉시 토큰 무효화**
   - GitHub 토큰: GitHub 계정 설정 > Developer settings > Personal access tokens에서 해당 토큰 삭제
   - 다른 서비스 토큰: 해당 서비스의 관리 콘솔에서 토큰 무효화

2. **새 토큰 발급**
   - 필요한 권한만 부여하여 새 토큰 발급

3. **Git 히스토리 정리**
   - 토큰이 커밋된 경우, Git 히스토리에서 해당 정보를 제거하는 것이 좋습니다.
   - 주의: 이미 공개 저장소에 푸시된 경우 히스토리 수정만으로는 완전한 제거가 불가능할 수 있습니다.

## 안전한 토큰 공유 방법

1. **암호화된 채널 사용**
   - 토큰을 공유해야 할 경우 암호화된 메시징 앱이나 비밀번호로 보호된 문서를 사용하세요.

2. **일회용 링크 활용**
   - 토큰을 공유할 때 일회용 링크와 만료 시간이 있는 서비스를 활용하세요.

3. **권한 분리**
   - 가능하면 각 개발자나 서비스에 필요한 최소한의 권한만 가진 별도의 토큰을 발급하세요.
