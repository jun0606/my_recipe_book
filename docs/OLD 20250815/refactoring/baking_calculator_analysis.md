# 베이킹 계산기 분석 문서

## 개요
이 문서는 현재 존재하는 여러 버전의 베이킹 계산기 위젯을 분석하고, 각 버전의 특징과 차이점을 정리합니다.

## 베이킹 계산기 버전 비교

### 1. baking_calculator.dart
- **기본 기능**: 기본적인 베이킹 계산 기능
- **계산 모드**: 기본 배율 조정
- **UI 특징**: 간단한 입력 필드와 결과 표시

### 2. baking_calculator_improved.dart
- **개선된 기능**: 분할 계산 기능 추가
- **계산 모드**: 배율 조정, 분할 수량, 분할 무게
- **UI 특징**: 모드 선택 탭, 개선된 입력 필드

### 3. baking_calculator_enhanced.dart
- **고급 기능**: 7가지 계산 모드 지원, 하이라이트 기능
- **계산 모드**: 
  - 배율 조정
  - 분할 수량
  - 분할 무게
  - 배율+분할
  - 동적 비교
  - 최적 분할
  - 목표 수량
- **UI 특징**: 
  - 세그먼트 버튼으로 모드 선택
  - 모드별 맞춤형 입력 UI
  - 재료별 계산 결과 표시
  - 요리 모드에서 현재 단계 재료 하이라이트

### 4. baking_calculator_user_friendly_fixed.dart
- **사용자 친화적 개선**: 입력 방식 개선, 오류 처리 강화
- **계산 모드**: enhanced 버전과 동일
- **UI 특징**: 
  - 더 직관적인 입력 컨트롤
  - 개선된 오류 메시지
  - 사용자 피드백 강화

## 계산 모드 상세 분석

### 1. 배율 조정 (scaleAdjustment)
- **목적**: 레시피 전체 배율을 조정
- **입력**: 배율 값 (예: 0.5x, 1x, 2x)
- **출력**: 조정된 재료 양

### 2. 분할 수량 (splitByCount)
- **목적**: 레시피를 지정된 수량으로 분할
- **입력**: 분할 수량 (예: 2개, 4개)
- **출력**: 분할된 재료 양, 분할 무게

### 3. 분할 무게 (splitByWeight)
- **목적**: 지정된 무게로 레시피 분할
- **입력**: 분할 무게 (예: 100g)
- **출력**: 분할 수량, 분할된 재료 양

### 4. 배율+분할 (scaleAndSplit)
- **목적**: 배율 조정 후 분할
- **입력**: 배율 값, 분할 수량
- **출력**: 조정 및 분할된 재료 양

### 5. 동적 비교 (dynamicComparison)
- **목적**: 다양한 분할 옵션 비교
- **입력**: 분할 무게, 분할 수량
- **출력**: 비교 결과, 최적 옵션 제안

### 6. 최적 분할 (optimalSplit)
- **목적**: 재료 낭비 최소화 분할
- **입력**: 목표 분할 무게 또는 수량
- **출력**: 최적화된 분할 결과

### 7. 목표 수량 (targetCount)
- **목적**: 특정 수량을 만들기 위한 재료 계산
- **입력**: 목표 수량 (개)
- **출력**: 필요한 재료 양

## 리팩토링 방향
1. **baking_calculator_enhanced.dart**를 기본 템플릿으로 사용
2. **baking_calculator_user_friendly_fixed.dart**의 사용자 친화적 개선사항 통합
3. 계산 로직과 UI 분리
4. 각 계산 모드를 전략 패턴으로 구현
5. 테스트 자동화 구현
