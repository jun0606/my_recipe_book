# 수쉐프 모드(제과·제빵·디저트) 설계 문서 V1.4

## 1. 개요

수쉐프 모드는 빵, 케이크, 쿠키, 디저트(푸딩, 아이스크림, 젤리, 사탕 등)별 전문 분석 모듈을 통해 레시피 분석, 환경 보정, 공정 최적화를 수행하는 시스템이다. 각 모듈은 **기후학, 사용자환경정보, 물리학, 미생물학, 제과제빵공학, 식품공학, 화학**을 종합 분석한다. 현재 구현이 어려운 기능도 향후 확장을 고려하여 설계에 포함한다.

---

## 2. 공통 분석 파이프라인

1. **레시피 입력** → 제목, 재료, 공정, 비율, 키워드 추출
2. **모듈 자동 선택** → 키워드, 공정 단계, 재료 구성 기반 100% 정확도 선택 및 검증
3. **환경 정보 입력** → 온도, 습도, 기압, 계절, 발효기·오븐 정보 입력
4. **재료별 특성 감지**
   - 물리·화학적 성질, 기능, 반응성, 흡수율, 수분함량, pH, 지방·단백질 함량, 발효성, 국가·지역별 품종 특성, 가공 방식 차이 등 감지
   - 예: 밀가루(글루텐 함량·품종별 특성), 버터(수분·지방 비율·원산지별 풍미 차이), 설탕(결정 크기·정제도), 계란(점도·산란환경 영향), 초콜릿(카카오버터 함량·산지 특성)
   - 감지 결과는 `재료 메타데이터`로 저장
5. **재료 메타데이터 생성** → 환경 보정 포함
6. **공정 분석 및 가이드 생성** → 믹싱, 발효, 굽기 등 단계별 최적 조건 산출
7. **실시간 센서 데이터 연동 준비** *(확장성 확보)* → 온도·습도·압력·pH 센서 연동 구조 설계, 실시간 메타데이터 업데이트 가능하도록 API/DB 스키마 설계
8. **알람 및 실시간 피드백 제공**

## 3. 모듈별 설계

### 3.1 빵 모듈

- 도법 판정: 스트레이트, 중종법, 풀리쉬, 비가, 탕종, 르방, 사워도우, 호밀 스타터 등
- 믹서 속도·시간 가이드: 저속·중속·고속 단계별 분·초 단위 추천
- 반죽 상태 메타데이터 생성 및 예상 완성 품질 분석
- 발효 프로세스 메타데이터 생성: 환경·재료 특성 기반 최적 발효 조건
- 오븐 설정 메타데이터 생성: 장비 사양·열전달 방식·스팀 여부 반영

### 3.2 케이크 모듈

- 공정 모델: 크리밍법, 공립법, 별립법, 시폰법
- 재료 특성 기반 반죽 안정성·구조 예측
- 굽기 전·중·후 상태 메타데이터 생성 및 코어 온도 목표 제공

### 3.3 쿠키 모듈

- 스프레드 예측 지수 산출 (지방, 당, 수분 비율 기반)
- 숙성 시간·온도·팬닝 간격 최적화
- 굽기 메타데이터 생성 및 식감 예측

### 3.4 디저트 모듈 *(강화 및 확장성 반영)*

- **푸딩**: 응고 온도·시간·pH 범위 분석, 단백질 응고 곡선 생성 → `푸딩 메타데이터` 저장
- **아이스크림**: 유지방·공기 함량(오버런) 제어, 결정 크기 예측, 냉동 속도 곡선 생성 → `아이스크림 메타데이터` 저장
- **젤리**: 젤화제 농도·온도 곡선, pH·당도 영향 분석 → `젤리 메타데이터` 저장
- **사탕**: 가열 온도·당 농도·결정화 제어, 습도 영향 분석 → `사탕 메타데이터` 저장
- 원료 변동 대응 모델: 대체 원료 사용 시 품질 변화 예측 로직 설계 *(확장용)*
- 저장·유통 중 품질 변화 모델링: 온도·습도·시간에 따른 텍스처·맛 변화 곡선 생성 *(확장용)*
- 각국·지역별 전통 디저트 특성 데이터베이스 구축 *(예: 프랑스 푸딩 vs 일본 푸딩, 이탈리아 젤라토 vs 미국 아이스크림)*
- 각 디저트 공정별로 환경·재료 보정 포함한 `디저트 종합 메타데이터` 생성
- 메타데이터 기반으로 굳힘/냉각/결정화 타이밍, 기구 설정, 알람 시점 제공
