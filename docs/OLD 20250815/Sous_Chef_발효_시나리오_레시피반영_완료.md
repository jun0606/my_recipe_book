# Sous Chef 발효 시나리오 레시피 반영 완료

## 🎯 개요
기본 발효 시나리오가 환경 정보만 반영하고 레시피 정보를 무시하던 문제를 해결하고, 커스텀 시나리오 빌더를 단순화했습니다.

## ✅ 완료된 작업

### 1. 레시피 정보 기반 발효 시간 조정 시스템 구축
- **파일**: `lib/widgets/fermentation/fermentation_timer_widget.dart`
- **새로운 메서드**: `_calculateRecipeBasedAdjustment()`
- **기능**:
  - 밀가루 종류별 발효 시간 조정 (강력분 +20%, 통밀 +30%)
  - 이스트 양에 따른 조정 (많으면 -20%, 적으면 +30%)
  - 당분 첨가 시 발효 시간 단축 (-10%)
  - 소금 양에 따른 조정 (많으면 +10%)
  - 레시피 제목 기반 조정 (바게트 +40%, 피자 -20%)

### 2. 기본 시나리오 생성 로직 개선
- **변경사항**:
  - `_createPredefinedScenarios()` 메서드에 레시피 정보 파라미터 추가
  - 환경 조건과 레시피 정보를 모두 반영하는 복합 계산
  - 시나리오 이름과 설명에 레시피 정보 반영
  - 발효 시간 범위 확대 (60-240분으로 조정)

### 3. 커스텀 시나리오 빌더 단순화
- **파일**: `lib/widgets/fermentation/advanced_scenario_selector.dart`
- **제거된 기능**:
  - AI 추천 탭 및 관련 설정들
  - 환경별 시나리오 탭
  - 복잡한 AI 설정 UI
- **남은 기능**:
  - "내 시나리오" 탭 (저장된 커스텀 시나리오)
  - "새로 만들기" 탭 (새 시나리오 생성)

## 🧮 레시피 기반 조정 로직

### 밀가루 종류별 조정
```dart
if (flourName.contains('강력분') || flourName.contains('bread')) {
  timeFactor *= 1.2; // 강력분은 발효 시간 20% 증가
} else if (flourName.contains('통밀') || flourName.contains('whole')) {
  timeFactor *= 1.3; // 통밀가루는 발효 시간 30% 증가
}
```

### 이스트 양에 따른 조정
```dart
if (yeastAmount > 10) { // 10g 이상
  timeFactor *= 0.8; // 이스트 많으면 발효 시간 20% 단축
} else if (yeastAmount < 5) { // 5g 미만
  timeFactor *= 1.3; // 이스트 적으면 발효 시간 30% 증가
}
```

### 레시피 제목 기반 조정
```dart
if (title.contains('바게트') || title.contains('baguette')) {
  timeFactor *= 1.4; // 바게트는 긴 발효 필요
} else if (title.contains('피자') || title.contains('pizza')) {
  timeFactor *= 0.8; // 피자는 짧은 발효
}
```

## 📊 시나리오 개선 결과

### 이전 (문제점)
- 모든 시나리오가 동일한 150분 발효 시간
- 레시피 정보 완전 무시
- 환경 조건만 부분적으로 반영

### 개선 후
- 레시피별 맞춤 발효 시간 (60-240분 범위)
- 재료 성분 분석 기반 정확한 조정
- 환경 + 레시피 복합 계산
- 시나리오 이름에 조정 이유 표시

## 🎯 사용자 경험 개선

### 1. 정확한 발효 시간
- **바게트**: 기본 90분 → 126분 (40% 증가)
- **피자 도우**: 기본 90분 → 72분 (20% 단축)
- **통밀빵**: 기본 90분 → 117분 (30% 증가)
- **이스트 많은 빵**: 기본 90분 → 72분 (20% 단축)

### 2. 단순화된 커스텀 빌더
- 복잡한 AI 설정 제거로 사용성 향상
- 핵심 기능에 집중 (저장/불러오기, 새로 만들기)
- 탭 수 감소 (4개 → 2개)

## 🔧 기술적 구현

```dart
class RecipeAdjustment {

}
```

final finalTimeFactor = altitudeFactor * recipeAdjustment.timeFactor;
