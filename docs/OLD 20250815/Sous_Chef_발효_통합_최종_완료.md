### 프리셋 시나리오 시스템
- 🚀 **빠른 식빵** (2-3시간): bulk + finalProof
- 📋 **표준 식빵** (4-5시간): bulk + divided + shaped + finalProof  
- 🌙 **오버나이트** (12-16시간): bulk + overnight + finalProof
- 🍞 **사워도우** (24-48시간): bulk + coldRetard + finalProof

## 🧪 통합 조언 예시

### 시나리오: 여름철 표준 식빵
**입력 조건**:
- 실내온도: 28°C, 습도: 70%
- 선택 단계: bulk + divided + shaped + finalProof
- 컨벡션 오븐

**통합 조언**:
```
🌡️ 발효 조건
- 1차 발효: 26°C에서 90분 (기존 120분에서 단축)
- 분할 후: 24°C에서 15분
- 성형 후: 26°C에서 12분  
- 최종 발효: 30°C에서 45분

🧪 재료 조정
- 이스트: 4.5g (기존 5g에서 0.5g 감소)
- 수분: 현재 수분율 유지
- 소금: 현재 비율 유지

🔥 오븐 설정
- 온도: 165°C (컨벡션 보정 -15°C)
- 시간: 35분
- 팬 속도: 중간

⚠️ 주의사항
- 높은 실내온도로 과발효 위험
- 70분 후 손가락 테스트 필수
- 습도 높아 표면 건조 주의
```
