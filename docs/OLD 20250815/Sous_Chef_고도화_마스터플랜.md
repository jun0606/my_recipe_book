# Sous Chef 모드 고도화 마스터 플랜

## 🎯 **핵심 목표**

수쉐프 모드를 **"단순한 조언 도구"**에서 **"지능형 베이킹 파트너"**로 진화시키기

### **핵심 전제: 레시피 데이터 완전 연동**
- 수쉐프 모드는 `RecipeDetailScreen`의 `_calculatedIngredients` 데이터에 직접 접근
- 실시간 재료 변경사항 (베이킹 계산기, 서빙 계산기) 반영
- 정확한 무게 기반 과학적 분석 및 조언 제공

### **1.1 수쉐프 모드 데이터 브릿지 구축**

#### **구현 파일**: `lib/services/sous_chef_data_bridge.dart`
```dart
class SousChefDataBridge {
  // RecipeDetailScreen에서 실시간 재료 데이터 수신
  static Map<String, dynamic> extractRecipeData(Recipe recipe, List<Map<String, dynamic>> calculatedIngredients);
  
  // 재료 데이터를 수쉐프 엔진이 이해할 수 있는 형태로 변환
  static Map<String, dynamic> prepareForSousChef(Map<String, dynamic> recipeData);
  
  // 총 무게 계산
  static double calculateTotalWeight(List<Map<String, dynamic>> ingredients);
}
```

## 📊 **새로운 수쉐프 모드 플로우**

### **기존 플로우**
```
레시피 상세 → 수쉐프 버튼 → 환경설정 → 조언 받기
```

### **고도화된 플로우**
```
레시피 상세 → 수쉐프 버튼 → 
├─ 📊 즉시 레시피 분석 (재료 데이터 기반)
│   ├─ 수분율: 72% (촉촉함)
│   ├─ 이스트: 1.8% (적정)  
│   └─ 베이커스 퍼센트 표시
├─ 🎯 현재 예상 특성 (Before)
│   ├─ 식감: 촉촉하고 쫄깃함
│   ├─ 풍미: 고소하고 담백함
│   └─ 외관: 연한 갈색 크러스트
├─ ⚙️ 환경 조건 입력
│   ├─ 온도: 26°C, 습도: 60%
│   └─ 오븐: 컨벡션, 팬 색상: 밝음
├─ 🧪 실시간 최적화 계산
│   ├─ 이스트 4.5g → 4.0g (-0.5g)
│   ├─ 발효시간 120분 → 100분 (-20분)
│   └─ 굽기온도 180°C → 165°C (-15°C)
├─ 📈 최적화 후 특성 (After)
│   ├─ 식감: 더욱 촉촉하고 부드러움
│   ├─ 풍미: 깊은 발효향 추가
│   └─ 외관: 균일한 갈색 크러스트
├─ 🔄 Before/After 비교
│   └─ 개선점 하이라이트
└─ 💾 최적화된 레시피 적용
    └─ RecipeDetailScreen에 반영
```
