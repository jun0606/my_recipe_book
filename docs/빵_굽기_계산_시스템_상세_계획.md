# 빵 굽기 계산 시스템 상세 계획 문서

## 시스템 아키텍처 개요

### 1. 핵심 컴포넌트
- `BakingCalculator` 클래스: 메인 계산 엔진
- `BreadConstants`: 중앙화된 상수 관리
- `BakingStepResult`: 단계별 결과 데이터 구조
- `BakingProcessResult`: 전체 프로세스 결과

### 2. 계산 파이프라인
```
사용자 입력 → 재료 비율 계산 → 마이야르 반응 → 크럼브 진행률 → 최종 결과
     ↓           ↓           ↓           ↓           ↓
ovenSteps   ingredientRatios  tempEffect   crumbProgress  bakingSuccess
```

## 상세 계산 로직

### 1. 재료 비율 계산 (_calculateIngredientRatios)
```dart
// 입력: recipeData['ingredients']
// 출력: flourRatio, waterRatio, doughWeight

// 밀가루, 물, 기타 재료 분류 및 무게 계산
// 비율 계산: flourRatio = flourWeight / doughWeight
```

### 2. 마이야르 반응 계산
```dart
// 온도 효과: tempEffect = pow(ovenTemp / referenceTemp, exponent)
// 습도 효과: moistureEffect = 1.0 - (moisture / 100.0)
// 산도 효과: acidityEffect = 1.0 + (acidity / 10.0)
// 시간 효과: timeEffect = pow(stepTime, timeExponent)

// 최종 마이야르: maillard = tempEffect * moistureEffect * acidityEffect * timeEffect
```

### 3. 크럼브 진행률 계산 (_calculateExponentialHeatTransfer)
```dart
// 빵 굽기 3단계별 열 전달 계수
double k = _calculateBakingStageHeatTransferCoefficient(stepNumber, maillardReaction);

// 뉴턴의 냉각 법칙 적용
double temperatureRise = targetTemp - (targetTemp - initialTemp) * exp(-k * bakingTime);

// 크럼브 진행률 (온도 기반)
double crumbProgress;
if (temperatureRise >= 70.0) {
  crumbProgress = min(1.0, (temperatureRise - 70.0) / 25.0);
} else {
  crumbProgress = 0.0;
}
```

### 4. 열 전달 계수 계산 (_calculateBakingStageHeatTransferCoefficient)
```dart
// 빵 굽기 단계별 k값 (빵 과학적 현실 반영)
if (stepNumber <= 1) {
  baseK = 0.01;  // 초기: 수분 증발 느림
} else if (stepNumber <= 2) {
  baseK = 0.02;  // 중기: 빠른 온도 상승
} else {
  baseK = 0.015 + (maillardReaction * 0.0001);  // 후기: 마이야르 동적 반영
}
```

### 5. 최종 베이킹 성공률 계산
```dart
// 마이야르와 크럼브 가중치 적용
double maillardRatio = maillardReaction / 100.0;
double maillardWeight = 0.3 + (maillardRatio * 0.2);
double crumbWeight = 0.7 - (maillardRatio * 0.1);

double maillardContribution = (maillardReaction / 100.0) * maillardWeight;
double crumbContribution = crumbProgress * crumbWeight;
double bakingSuccess = maillardContribution + crumbContribution;
```

## 빵 과학적 구현 특징

### 1. 뉴턴의 냉각 법칙 기반 열 전달
- **물리 법칙 적용**: 실제 빵 굽기 현상을 정확하게 모델링
- **지수 함수**: 온도 상승의 비선형적 특성 반영
- **동적 계수**: 마이야르 반응에 따른 열 전달 효율 변화

### 2. 빵 굽기 3단계 모델
```
초기 (0-10분): k=0.01 - 수분 증발, 느린 열 전달
중기 (10-30분): k=0.02 - 빠른 온도 상승, 팽창
후기 (30분-): k=0.015 + 마이야르 영향 - 마이야르 반응, 색상 형성
```

### 3. 온도 기반 크럼브 진행률
- **70°C 이상**: 크럼브 익힘 시작
- **95°C 목표**: 완전 익힘
- **선형 진행**: 70°C(0%) → 95°C(100%)

### 4. 마이야르 반응 동적 반영
- **온도 효과**: 지수 함수 기반
- **습도 효과**: 반응 억제/촉진
- **산도 효과**: 발효 산도 증폭
- **시간 효과**: 비선형 반응 곡선
